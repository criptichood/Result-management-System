# 03. Grading Engine & Academic Rules

The FUAZ SRMS implements the standard 5-point Cumulative Grade Point Average (CGPA) system approved by the Nigerian National Universities Commission (NUC).

---

## 1. Score Breakdown & Letter Grade Scale

Every registered course is evaluated out of 100 percentage points:
$$\text{Total Score} = \text{Continuous Assessment (CA, Max 40)} + \text{Semester Examination (Max 60)}$$

### Standard 5.0 Nigerian University Scale:

| Score Range | Letter Grade | Grade Point (GP) | Academic Interpretation |
| :--- | :---: | :---: | :--- |
| **70% – 100%** | **A** | **5.0** | Excellent / Distinction |
| **60% – 69%** | **B** | **4.0** | Very Good |
| **50% – 59%** | **C** | **3.0** | Good / Satisfactory |
| **45% – 49%** | **D** | **2.0** | Fair / Pass |
| **40% – 44%** | **E** | **1.0** | Marginal Pass |
| **0% – 39%** | **F** | **0.0** | Fail (Carryover Required) |

---

## 2. Mathematical Computation Formulas

### Weighted Points (WP) per Course:
$$\text{Weighted Points} = \text{Credit Units (CU)} \times \text{Grade Point (GP)}$$
*Example: A 3-unit course with a score of 74 (Grade A, GP = 5.0) yields $3 \times 5 = 15.0$ weighted points.*

### Semester Grade Point Average (GPA):
$$\text{GPA} = \frac{\sum (\text{Credit Units} \times \text{Grade Point})}{\sum \text{Credit Units}} = \frac{\text{Total Weighted Points (TWP)}}{\text{Total Credit Registered (TCR)}}$$

### Cumulative Grade Point Average (CGPA):
$$\text{CGPA} = \frac{\sum_{\text{all semesters}} \text{TWP}}{\sum_{\text{all semesters}} \text{TCR}}$$

---

## 3. Degree Classifications (Nigerian 5.0 Scale)

At graduation or evaluation checkpoints, the student's academic standing is classified as follows:

| CGPA Range | Degree Classification | Standing |
| :--- | :--- | :--- |
| **4.50 – 5.00** | **First Class Honours** | Excellent Standing |
| **3.50 – 4.49** | **Second Class Honours (Upper Division)** | Very Good Standing |
| **2.40 – 3.49** | **Second Class Honours (Lower Division)** | Good Standing |
| **1.50 – 2.39** | **Third Class Honours** | Fair Standing |
| **1.00 – 1.49** | **Pass Degree** | Pass / Marginal |
| **< 1.00** | **Probation / Withdrawal** | Academic Warning / Probation |

---

## 4. Carryover & Retake Academic Rules

1. **Compulsory Core Course Failures**:
   - Any student with an **F (0.0)** in a core departmental course must register and retake the course in the subsequent relevant semester.
2. **Impact on Cumulative Units**:
   - Registered credit units count in TCR in both attempts, diluting CGPA unless cleared with a high subsequent score.
3. **Graduation Clearance**:
   - A student cannot be cleared by Senate for graduation if they have unresolved carryovers in compulsory or required university-wide courses.
